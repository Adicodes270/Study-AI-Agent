Quick Guide · Free

How to get a Gemini API key

Google provides free Gemini API keys to anyone with a Google account—no credit card needed.

  1. 1
    Open Google AI Studio

    Visit aistudio.google.com/app/apikey and sign in with your Google account.

  2. 2
    Click "Create API key"

    Press the blue Create API key button in the top-right corner and select any project (or click Create API key in new project).

  3. 3
    Copy & paste it here

    Click Copy on the generated key (it starts with AIzaSy...) and paste it into the Primary Key box on the left.

Pro tip for exam week: Create 2 or 3 keys in different Google projects and add them as fallbacks so you never wait on rate limits.

How NotebookLM sign-in works

We handle the notebooklm-py session setup through a normal Google sign-in window so you never have to run terminal commands.

  1. 1
    Click "Sign in with Google"

    A dedicated Google NotebookLM sign-in window will pop up on your screen.

  2. 2
    Log into your Google Account

    Sign in normally and approve 2-Step Verification on your phone if prompted until you see your NotebookLM notebooks page.

  3. 3
    Close the popup window

    As soon as you close the popup window (or click I've Signed In — Confirm), Study Agent locks in your NotebookLM connection!
