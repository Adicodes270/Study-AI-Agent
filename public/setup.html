Quick Guide · Free

How to get a Gemini API key

Google provides free Gemini API keys to anyone with a Google account—no credit card needed.

  1. 1
    Open Google AI Studio

    Visit aistudio.google.com/app/apikey and sign in with your Google account.

  2. 2
    Click "Create API key"

    Press the blue Create API key button in the top-right corner and select any project (or click Create API key in new project).

  3. 3
    Copy & paste it here

    Click Copy on the generated key (it starts with AIzaSy...) and paste it into the Primary Key box on the left.

Pro tip for exam week: Create 2 or 3 keys in different Google projects and add them as fallbacks so you never wait on rate limits.

How to get your Todoist API Key

Follow these three quick steps to copy your personal Todoist API token:

  1. 1
    Log in to Todoist

    Sign in to your Todoist account in your browser if you haven't already.

  2. 2
    Open Todoist Developer Settings

    Visit https://app.todoist.com/app/settings/integrations/developer in a new tab.

  3. 3
    Copy & paste your API token

    Under the API token section, click Copy to clipboard and paste your token into the input field on the left, then click Verify & Save Key.

Server fallback supported: You can also set TODOIST_API_KEY in your .env file as a default fallback.
